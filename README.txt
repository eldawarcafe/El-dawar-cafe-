الدوار كافيه - المنيو الإلكتروني
================================

محتويات المشروع:
- index.html: صفحة الموقع.
- style.css: التصميم والألوان.
- menu.js: الأصناف والأسعار (يمكن تعديلها بسهولة).
- assets/logo.jpg: شعار الكافيه.

مهم:
1) الموقع للعرض فقط، لا يحتوي على طلبات أو دفع.
2) لتعديل صنف أو سعر، افتح menu.js وعدّل الاسم أو الرقم.
3) عند إضافة صنف، أضف عنصرًا بنفس الصيغة داخل items في القسم المناسب:
   { name: "اسم الصنف", price: 25 }

النشر:
ارفع محتويات المجلد إلى مستودع GitHub جديد، ثم فعّل GitHub Pages من:
Settings > Pages > Deploy from a branch > main > /(root) > Save
قد يستغرق ظهور الموقع عدة دقائق.
